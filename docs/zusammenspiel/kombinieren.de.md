## Überblick

Die Stärke von OKW zeigt sich, wenn mehrere Bibliotheken in einem
Test zusammenwirken. Alle OKW-Bibliotheken teilen dieselbe
Keyword-Philosophie und lassen sich nahtlos kombinieren.

## Typische Kombinationen

| Kombination | Use Case |
|---|---|
| Docker + Web Selenium | Container hochfahren, Webanwendung testen |
| REST API + Web Selenium | Testdaten per API anlegen, UI prüfen |
| Kafka + REST + GUI | Nachricht senden, API-Verarbeitung prüfen, Ergebnis in GUI verifizieren |
| SSH + GUI | Server konfigurieren, Auswirkung in der Anwendung prüfen |
| Proxmox + Docker + GUI | VM provisionieren, Container starten, Anwendung testen |
