# Proxmox

!!! info "Work in progress"

## Overview

The library `robotframework-okw-env-proxmox` provisions virtual machines
and LXC containers on Proxmox VE — as test environments for integration
tests.

## Installation

```bash
pip install robotframework-okw-env-proxmox
```
