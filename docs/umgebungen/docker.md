# Docker

!!! info "Work in progress"
    This chapter is still being written.

## Overview

The library `robotframework-okw-env-docker` provisions Docker containers
as test environments and tears them down again — directly from Robot
Framework.

## Installation

```bash
pip install robotframework-okw-env-docker
```

## Runnable Examples

See [env-docker/](https://github.com/Hrabovszki1023/okw-examples/tree/master/env-docker)
in the okw-examples repository.
