## Überblick

Die Bibliothek `robotframework-okw-env-docker` ermöglicht es,
Docker-Container als Testumgebungen automatisiert bereitzustellen
und wieder abzuräumen — direkt aus Robot Framework heraus.

## Installation

```bash
pip install robotframework-okw-env-docker
```
