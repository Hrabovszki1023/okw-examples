## Überblick

Die Bibliothek `robotframework-okw-remote-ssh` ermöglicht die Ausführung
von Befehlen auf entfernten Systemen über SSH — für Integrations- und
Infrastrukturtests.

## Installation

```bash
pip install robotframework-okw-remote-ssh
```
