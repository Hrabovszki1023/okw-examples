## Überblick

Die Bibliothek `robotframework-okw-java-remoteswing` ist der OKW-Treiber
für Java Swing Desktop-Anwendungen. Sie nutzt die RemoteSwingLibrary,
die über einen Java-Agent in die laufende Anwendung injiziert wird.

## Installation

```bash
pip install robotframework-okw-java-remoteswing
```
