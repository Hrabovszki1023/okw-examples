# Java RemoteSwing

!!! info "Work in progress"
    This chapter is still being written.

## Overview

The library `robotframework-okw-java-remoteswing` is the OKW driver for
Java Swing desktop applications. It uses RemoteSwingLibrary, which is
injected into the running application via a Java agent.

## Installation

```bash
pip install robotframework-okw-java-remoteswing
```
